\subsection{Full MP-20 recovery and repeated WBM fits}\label{s:revision-scale}
We evaluated the frozen full-chemistry generators and training-geometry retrieval on all 9,046 structures in the public MP-20 test split. For each of the three original seeds, all four methods received the same atomic numbers and multiplicities. The neural models shared their initial noise. The first five proposals for the original 128 hash-selected targets were preserved exactly. For every target and draw we recorded the normalized RMS criterion from \texttt{get\_rms\_dist}, the maximum-site criterion from \texttt{fit}, and the native generated-to-reference volume ratio. The volume sensitivity accepts an RMS-matched draw only when this ratio lies between $1/1.10$ and $1.10$. Both pymatgen matchers use the original lattice and site tolerances, primitive reduction, and isotropic rescaling.

\subsection{Replication on formula-disjoint WBM}
For WBM we repeated the paired training with seeds 23 and 37, using the original 205,091 structures, 12,819 updates and the same 128 held-out targets as seed 11. The five-draw RMS-recovered target counts for seeds 11, 23 and 37 were $(39,40,37)$ for drift and $(28,35,27)$ for one-step flow. Their paired recovery difference was $+6.77$ percentage points ($[2.60,10.94]$). With the native-volume rule it was $+3.91$ points ($[-0.52,8.07]$). The held-out formulas are disjoint from WBM training. Geometry retrieval can therefore recover an arrangement by assigning the supplied species to sites from a training template.

The accelerated matcher uses a necessary lattice-frame and site-subset test when the native and primitive reference cells contain the same number of sites. Primitive reduction changed the count for 130 of the 9,046 MP-20 references. Those cases went directly to pymatgen. An independent check used both public matcher calls on 6,144 draws from 512 separately hash-selected targets. Every RMS and maximum-site hit indicator agreed, and the largest normalized RMS difference among matched pairs was $<10^{-8}$.
