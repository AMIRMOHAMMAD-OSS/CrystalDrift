# Published uFlowCSP one-step replay

The replay uses Sourin Dey and Jianjun Hu's published Cartesian MP-20 model. The repository's newer fractional-coordinate model reports separate results and its README says weight download links are forthcoming. The Cartesian code is MIT licensed. The published checkpoint is CC BY 4.0. [Cartesian implementation](https://github.com/usccolumbia/uFlowCSP/tree/e87af8483e6d45b0217b4ede430862e992d2b1d0) · [Published checkpoint](https://doi.org/10.6084/m9.figshare.33974422.v1) · [Paper](https://arxiv.org/abs/2609.09799)

The two-site replay produced 945 unrelaxed structures, five for each of the 189 held-out binary MP-20 records. The model received the two elements with their exact cell counts. The crystal system and space-group inputs used the null label. All 189 reference IDs occur in the authors' 9,046-ID test split and none occurs in their 27,136-ID training split. Their training script uses the DiffCSP split and further excludes the 180-material benchmark list. The authors trained on a much larger collection of MP-20 structures than the restricted two-site models in this pilot. [Pinned training script](https://github.com/usccolumbia/uFlowCSP/blob/e87af8483e6d45b0217b4ede430862e992d2b1d0/scripts/train.sh)

`seed2026-euler1.npz` stores `ids[189]`, sorted `z[189,2]`, log-Gram `k[189,5,6]` and relative fractional positions `f[189,5,3]`. `crosswalk.csv` records the test ID, original species order and the model's electronegativity-ordered tokens. The sampler used all 100 input positions prescribed by the checkpoint and exactly one denoiser evaluation for each candidate. The released code supplied the prior, MeanFlow step and EMA network forward. Decoding averaged the active Cartesian lattice tokens and converted the Cartesian positions using the pseudoinverse of the row-vector cell matrix. The export preserves every raw candidate before the authors' optional CLI validity filtering, so invalid outcomes remain available to the shared evaluation. [Official generation and decoding](https://github.com/usccolumbia/uFlowCSP/blob/e87af8483e6d45b0217b4ede430862e992d2b1d0/src/models/meanflow_raw_module.py)

The checkpoint is a 3,148,174,712-byte PyTorch ZIP that also contains saved Python objects and optimizer state. `uflowcsp_weights.py` reads the ZIP directory, restricts tensor metadata parsing to the initial state dictionary, validates that its callable identifiers are limited to a tensor rebuild and standard storage types, and uses PyTorch's weights-only fake-tensor loader. It copies the 141 EMA tensors directly to a 524,860,464-byte weight payload, checking every tensor against its archived CRC. Inference reads this subset through safetensors and requires a strict match to the restored 131,215,116 network parameters. Figshare's MD5 in `figshare.json` identifies the full release. Only the EMA records were downloaded and checked.

Inference used PyTorch 2.7.1 CPU and the authors' specified timm 1.0.21. The runtime pymatgen version was 2024.4.13. Its atomic radii and electronegativities agreed for all 118 elements with the authors' pinned 2025.10.7 table. The periodic group implementation agreed and all row numbers matched. The two-site run took 94.2 seconds for 945 candidates with three CPU threads, batch size 12 and seed 2026. The timing covers generation and conversion into the common geometry representation, and excludes model loading and file writing. `replay.json` records the run.

## Binary cells with two to eight sites

The multisite replay used the same 128 targets as the compact models' structure-matching benchmark. The evaluator selects the first 128 material IDs from the 1,229-record binary test split after sorting by SHA256 of each ID. All 128 occur in uFlowCSP's test split, with zero IDs in its train split. Sixteen of the selected cells have two sites and 112 have three to eight. The checkpoint received the exact integer count of each element in the primitive cell. The sampler kept the null symmetry label and the two-site run's noise distribution, random seed, batch size, thread count and single-evaluation settings. Decoding averaged the active site lattice predictions and restored the fractional coordinates to ascending atomic number. Vacant array positions have zero padding.

Generating 640 candidates took 54.34 seconds in total (84.91 ms per crystal). The shared pymatgen StructureMatcher recovered 68/128 references on the first sample (53.13%) and 103/128 within five (80.47%), with zero matching exceptions. The 16 two-site cases contributed 13 first-sample recoveries and 16 within five. The 112 structures with three to eight sites contributed 55 and 87, respectively. `multi-seed2026-euler1.npz` contains `ids[128]`, `z[128,8]`, `k[128,5,6]` and `f[128,5,8,3]`. `multi-crosswalk.csv` records split membership and species order. `multi-replay.json` records runtime and settings. The per-candidate RMS errors are in `../structure-matching/multi-uflow-2026.json`.

From the `crystal-drift` directory, with the above packages available, run the weight extractor and then the replay. `--site` can add a directory for an isolated dependency installation.

```sh
python uflowcsp_weights.py
python uflowcsp_replay.py --weights <temporary-directory>/codex-uflowcsp-69274087/ema.safetensors
python uflowcsp_replay.py --cohort multi --weights <temporary-directory>/codex-uflowcsp-69274087/ema.safetensors
```
