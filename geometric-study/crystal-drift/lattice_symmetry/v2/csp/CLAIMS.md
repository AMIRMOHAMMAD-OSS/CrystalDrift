# Evidence for the composition-only comparison

| Endpoint | Source and independent check |
|---|---|
| Conditioning information | Only ascending per-cell elemental multisets and the seed noise are passed to the generators. The training prior uses exclusively `scaled/mp20-data/train.npz`. The fixed hash-sorted public cohort is crosswalked to all 9,046 public test structures in `verify.py`. No group, template, target-cell volume or target site is supplied. |
| Physical radial, power-zero and angular methods | `model.new_model` maps all three labels to the same width-24 physical generator. They differ in the prefix of the training descriptor. Training descriptors are absent from `load_service`. The power-zero experiment retains the local scalar contraction blocks that can already distinguish the 12-gon witness. |
| Backbone and flow attribution | Fixed-basis angular training maps to a width-24 set network with six bounded log-stretch residuals and bounded fractional site updates in the native convention. The matched compact flow maps to a separately fitted width-24 set velocity field and sixteen Euler integrations from the exact same physical prior. The earlier fixed-basis and one-step comparison weights are different fits. The earlier one-Euler result reuses the earlier iterative flow weights. |
| Positive and generated banks | `train.py` calls the original `scaled.family.within_direction` on eight independent four-by-four exact-composition banks. All pre-drawn positive IDs, conditional schedules and seed identities are recorded in `fits/*/schedule.npz`. `verify.py` checks each ref slot belongs to its scheduled composition and that all compared objectives share these arrays. |
| Source, optimizer, scale, width and costs | The training, physical and neighborhood sources associated with each checkpoint are hashed. `sources.py` reconstructs the original bytes of every recorded implementation version (including variants before introduction of the power-zero and prior-only controls) and places them in `source-versions`. Every fitted trajectory milestone has loss and gradient-norm traces, exposure, unique-bank histogram, optimizer hyperparameters, CPU/wall time, peak working set, model and code hashes. |
| Validation and archive seal | `stage.py` produces 128 target-level energy scores at five owned draws per seed. `lock.py` averages over all three fit seeds at each common duration. Selected weights, evidence digests and all intermediate selection snapshots referenced by the raw-bank manifests are under `selection.json` and `locks`. `training_figure.py` verifies and plots 45 candidate scores. `audit_banks.py` checks every output coordinate, padding entry, weight hash, pool hash, target order and draw count in all 18 banks. |
| Full-split fixed-draw recovery | `test/*/outcomes.npz` stores matcher RMS, strict-fit boolean, native-volume difference and exceptions for every draw. The prescreen and precise matcher are the pinned fixed-basis implementation in `revision/full/match_full.py`. Unmatched and failed attempts count in target-level MR denominators. `quality.csv`, `seeds.csv`, `sensitivities.csv` and `paired-draws.csv` derive from these records. The RMSE mean is conditional on matched targets within a given seed. |
| Timing | `gpu/*-episodes.npz` and `gpu/*-rms.npz` pair actual completion time and subsequent outcome for every proposal. `gpu/*-10000.npz` holds the separate batch-24 wall clock. `interleaved/shards` retains all six services' actual geometry and per-episode wall times in the balanced-order repeat. For both experiments `first-hit-events.csv` stores the uncensored first hit where observed. An unrecovered target contributes no event before its 20-draw limit. The original publication's fixed-basis deadline and present workstation repetitions have separate records. |
| Interval and figures | `report.py` uses 5,000 paired material-ID bootstrap samples to propagate target variability conditional on the fitted seeds. For a point on the exact first-hit empirical curve the marginal nonparametric bootstrap count is binomial; its quantiles give the angular ribbon. The vector plots use recorded first-hit times for the full capped stream. `paper.py` reads the verification seals and CSV reductions when generating the manuscript tables and numerical statements. |
| Host-only sensitivity | `cpu_clock.py` balances six services across 128 IDs and stores each of five B1 calls plus separate contiguous batch-24 workloads of 10,000. The settings, source-pool identities, outputs, per-call and batch times are under `cpu/`. These clocks use one CPU thread and the same host materialization boundary as the GPU comparison. |

The task-C results have their own conditional inputs, target set, models and geometry. They belong to the Wyckoff study; a change of protocol changes the inference information.
