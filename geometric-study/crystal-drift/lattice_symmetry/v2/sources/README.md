# Primary-literature audit

The source guide contains the numerical and architectural comparisons checked for this version. `guide.json` records the role of each paper and the location or quantity relevant to that role. `primary-records.json` gives 42 primary-source records, including the two crystallographic implementations. The checks resolve authors and titles against arXiv, publisher metadata or Crossref and record document hashes, full-text anchors, PDF page matches and outbound repository links where available. A locator is a navigation aid. Institutional boilerplate links returned by HTML pages do not establish model authorship. `code-locations.json` points to specific public implementations, commit identifiers and lines examined. Third-party performance claims in a particular conditioning, relaxation or time regime are not transplanted into local result tables.

On 20 November 2026 the terms “drifting models”, “attraction repulsion”, “periodic crystal”, “angular”, “crystal structure prediction”, “Wyckoff” and “kernel-gradient drifting” were queried in combinations. Among the primary results inspected, SymDrift develops drift in an invariant molecular embedding; GemsNet and periodic vector-field diffusion jointly transform sites and lattices; LEGO-xtal uses local angular power spectra for pre-relaxation. DiffCSP++, SGEquiDiff, SGFM and Orbitol constrain crystal geometry at a supplied symmetry. None of these specific formulations supplied the independent-bank periodic experiment reported here. The paper claims a particular adaptation and tests it under controlled budgets. This search cannot certify absolute priority.

Deng et al. use a frozen regression target and discuss two-sided normalization. SymDrift Eq. 14 groups and sorts distances by chemical pair, which loses edge incidence. Kernel-gradient drifting replaces empirical displacements by kernel-derived directions. LEGO-xtal Eq. S16 contracts angular coefficients, and Supplement S3.1 then uses the local-environment distance for structural optimization. The new implementation instead builds discrete neighbor densities on complete physical images, contracts at each site and fits the distribution of the pooled descriptors through a detached bank update. The scalar affinity does not define a normalized crystal diffusion transition.

The Wyckoff replication and baseline readers have separate source and checkpoint records. WyFormer supplies an occupational representation; its performance requires specifying whether coordinates and a cell have also been generated. A post-relaxation retained-group metric requires its own identity, selection, pressure, force tolerances and hull database. The C experiment measures containment and group equality on the same conformations with the same space-group finder. The previous release archives the exact DiffCSP validity and fingerprint implementation and the source versions for its uFlowCSP, compact flow and fixed-basis comparisons.

Run `python lattice_symmetry/v2/sources/check.py` and `python lattice_symmetry/v2/sources/code_check.py` to refresh public metadata separately from the experimental runs. Run `python lattice_symmetry/v2/sources/bibliography.py` after all manuscript fragments have been written. It emits a paper-only bibliography, retaining verified references shared with the sealed release.
