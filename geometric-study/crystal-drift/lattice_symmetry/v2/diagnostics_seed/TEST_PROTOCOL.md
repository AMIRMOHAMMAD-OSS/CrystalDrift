# Locked formula-conditioned transfer comparison

This comparison was specified after two validation cohorts and before inspecting or running these new proposal-arm results on the test set. Earlier papers and audits have already scored the released test split. The comparator weights are frozen. No change to the approach, draw allocation, volume treatment, subset, or endpoints follows inspection of these test results.

Select 384 unique official MP-20 test IDs by ascending SHA-256 of the UTF-8 string formed by the literal prefix `crytaldrift-onecall-transfer-confirm:` and the material ID. Each arm takes only the target cell composition. The validation procedure determines a maximum of ten distinct training donor structures per target, placed in alternating draws starting with draw one. Other slots use the existing composition-fitted physical prior. Rank eligible donors within the same site multiplicity pattern by the sum of the absolute atomic-number differences in sorted element lists; if the pattern is absent fall back to the same number of sites. Break ties with the same deterministic per-record RNG used in pilot.py. Adjust donor log volume with the difference in the original, train-only volume regression between target and donor compositions.

The primary intervention applies the released seed-11 angular checkpoint (256 updates) once per candidate. On donor slots preserve the fitted donor volume after that prediction, keeping its predicted positions and cell shape. Secondary controls are the identical mixed prior without a network call, the original angular generator from the plain prior, the same mixed prior with the unmodified angular update, and the plain physical prior. Keep reference RNG constants, count, and transforms identical to the validation experiment. Verify against the archived seed-11 angular outputs and published uFlowCSP one-call draw sequence with matched IDs.

Evaluate 1, 5 and 20 ordered draws using the pinned pymatgen 2024.4.13 matcher with the release's RMSD-match definition, and that match combined with |log native-cell volume ratio| ≤ log(1.1). Report the 9-or-more-atom stratum. Report gains and losses and paired 95% percentile bootstrap intervals based on resampling target IDs (10,000 replicates, seed 51039) against the archived uFlowCSP, archived angular, re-drawn angular, matching zero-call prior and unanchored mixed generator. Count errors as failed draws. Report the raw per-target/draw outcomes and exact input identities. Label this a prespecified 384-target held-out evaluation and refrain from extrapolating to a full-split score or original hardware timings.
