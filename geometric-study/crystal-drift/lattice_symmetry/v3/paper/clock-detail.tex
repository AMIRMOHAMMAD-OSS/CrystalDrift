The common train-only template index took 6.02 seconds to instantiate for the GPU clock. For the serial comparison we reset the shortlist cache at the beginning of each material, start the clock, and record synchronized elapsed time after each completed proposal. The random interleaving order is retained. The 20-draw cap applies equally to all methods and time budgets. No partial proposal is scored. In the repeated 10,000-composition workload, the sampler resets template lookup for each formula, and the final partial batch contains 16 structures. A one-call method invokes the network 313 times when tensor batches cover all 10,000 structures.
