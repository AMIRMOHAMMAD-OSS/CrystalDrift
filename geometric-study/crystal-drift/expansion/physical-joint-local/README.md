# Secondary physical replay

This directory accompanies the separately sampled 100-step joint CrystalFlow bank. [The prospective design](DESIGN.md) fixes its first sixteen positions, the energy reference and the final screen before the finished source bank was available.

Run these commands from the repository root in the primary CHGNet environment after the new raw pool is available.

~~~sh
python expansion/physical-joint-local/primary_snapshot.py
python expansion/physical-joint-local/screen.py --workers 3
python expansion/physical-joint-local/report.py
~~~

The second command accepts `--wait-for-pool` to start before the generation file has been atomically renamed. The exact trained weights, package versions, input pool checksum, reused phase checksums, and source IDs appear in `settings.json`. Only the shared physical implementation and primary records are read from the original five-arm experiment. New inputs, records, and starting and final candidate CIFs are under this directory. A phase can reuse a primary calculation only if the full input bytes and the recorded phase ID match. All other phases receive a fresh calculation.

`by-arm.csv` and `per-candidate.csv` are generated by the original physical evaluator pointed at these separately stored inputs and results. The supplementary checker independently verifies the first sixteen structures against the raw bank, runs a second linear-program solve of each complete competing-phase hull, and retests novelty and uniqueness against the original training archive and ordered relaxed candidates. It recomputes the final intersection, seen/unseen denominators, worker charges and complete local generation cost in `verification.json`. The same check compares the original five-arm inputs, records, CIFs and tabulations to the pre-run SHA-256 in `primary-before.json`. The LaTeX fragment is generated from those verified case-level outcomes.
