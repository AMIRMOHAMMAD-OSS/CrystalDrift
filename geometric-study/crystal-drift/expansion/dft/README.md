# Independent electronic-structure check

From the first sixteen compositions shared by the learned-prior generators, keep cells with at most four sites and atomic numbers at most 36. The first eligible draw is MgGa3, draw 7. Selection is independent of energy, forces, validity and CHGNet convergence. Evaluate raw and CHGNet-relaxed coordinates for drift and 16-step flow with identical scalar-relativistic PBE-PAW parameters at two k meshes. The observations compare fixed-composition energies and forces. The sample has one formula and contains no first-principles competing-phase library.

Inputs, converged outputs and per-atom force vectors are under this directory. The packaged Ubuntu Noble binary aborted before reading scientific inputs on this host. We used the SHA-256-verified Debian Bookworm build of Quantum ESPRESSO 6.7 (6.7-2+b1) with workspace-local ScaLAPACK. The four jobs per mesh each use one host thread and one MPI rank. A command-line program installed on another system can be supplied as QE_PW. The local Debian runtime is reproducible with `bash expansion/dft/setup.sh`, followed by `bash expansion/dft/run.sh` and `python expansion/dft/summary.py`. DFT costs are separate from CHGNet screening.
