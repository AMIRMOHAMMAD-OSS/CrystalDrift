# Evidence for the revised manuscript

All local paths below are relative to this research release. The binary and multielement models have different training sets and feature maps. Each comparison aligns the target ID, ordered candidates, supplying training split and matcher. A missed match contributes zero to recovery and has no normalized displacement. For ensembles with repeated fits, conditional mean best displacement is computed within fit and the fit means receive equal weight. Reported paired intervals resample material IDs and hold the fits fixed.

### Reproduce the two additional screens

Use the structure-matching environment described in the full-split guide for the first three commands. Install matminer 0.9.2 and SMACT 2.5.5 with its pinned NumPy, SciPy and pymatgen for the last one.

~~~sh
python revision/sensitivity/binary.py --workers 3
python revision/sensitivity/binary.py --external revision/binary/uflow-20.npz
python revision/sensitivity/binary.py --summarize
python revision/denovo/metrics.py --workers 3
~~~

The reported timings are local measurements. The Mac Studio and Jean Zay instructions reproduce the fitting procedures on another machine; their hardware has separate timing characteristics. This session had no configured Jean Zay allocation. [Cluster and Mac commands](../scaled/RUN.md) · [Archived software and CPU boundary](binary/settings.json)
